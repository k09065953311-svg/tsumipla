# 積みプラ帳

プラモデルの箱のバーコード（JANコード）をスマホで読み取って、持っているキットを一覧にするWebアプリです。

- バーコード読み取り（カメラ／写真／番号入力）
- Yahoo!ショッピング・楽天市場の商品検索APIで商品名・箱絵・定価（仮）を自動入力
- 所持数の＋／−、状態（積み・製作中・完成）、商品名検索、並び替え
- データは各自のスマホ（ブラウザ）の中に保存。バックアップの書き出し／読み込みあり
- 使い方マニュアル: manual.html（アプリの⚙設定からも開けます）
- `worker/yahoo-proxy.js`: Yahoo!ショッピング検索の中継（Cloudflare Worker）。Yahoo! V3 API は CORS 非対応のため

## 使い方（友達向け）
1. 配布されたURLをスマホのSafari / Chromeで開く
2. 共有メニューから「ホーム画面に追加」するとアプリのように使えます
3. 右上の⚙設定で Yahoo! の Client ID（または楽天のアプリID）を入れる

## 開発メモ
- 本体は `src/app.html`。`./build.sh` で `index.html`（GitHub Pages 用）と `artifact.html`（プレビュー用）を生成
- バーコード読み取りは ZXing（`lib/zxing.min.js`, Apache-2.0）
- メーカーサイトのスクレイピングはしない方針。公式ページへはリンクで案内する
